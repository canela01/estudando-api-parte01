# estudando-api-parte01

🧠 Conceitos Práticos Praticados
🛠️ Estrutura e Semântica (HTML5)
Criação de formulários ou containers de busca eficientes utilizando <form>, <input> e <button>.

Definição de áreas vazias (<div> ou <section>) prontas para receber e exibir o conteúdo que será injetado dinamicamente pelo JavaScript.

🎨 Estilização e Estados Visuais (CSS3)
Feedbacks Visuais: Criação de classes específicas de erro (.error) e sucesso para estilizar as respostas da API de forma adequada.

Layouts Flexíveis: Alinhamento centralizado do conteúdo e dos cards de resposta para garantir um design moderno.

⚡ Integração e Assincronismo (JavaScript & APIs)
Fetch API: Utilização do método nativo fetch() para realizar requisições HTTP (GET) para os endpoints da API.

Promises e Async/Await: Aplicação prática de sintaxe assíncrona moderna com async e await para gerenciar o tempo de resposta do servidor de forma limpa.

Manipulação de JSON: Conversão da resposta bruta recebida do servidor em um objeto manipulável via JavaScript utilizando .json().

Injeção Dinâmica no DOM: Manipulação do HTML em tempo real (.textContent e .innerHTML) para substituir os dados estáticos pelos dados reais vindos da API.

Blocos de Exceção (Try/Catch): Implementação de estruturas try...catch para capturar falhas de rede ou respostas inválidas de forma segura.
